## Git与Docker
| 工具 | 描述 | 场景 | 代表平台 |
|:---:|:---:|:---:|:---:|
| **Git** | 分布式版本控制工具 | 管**代码**：历史、分支、合并、回滚、多人协作 | GitHub、GitLab、Gitee |
| **Docker** | 容器化平台 | 管**运行环境**：把应用+依赖打包成镜像，到哪都能跑 | Docker Hub、GHCR、阿里云 ACR |

**Git**：管代码怎么变,开发时用，防止代码丢了、乱了、多人改冲突。  
**Docker**：管应用怎么跑,部署时用，防止“我电脑能跑，你电脑跑不了”。  
**二者关系**：写代码 -> Git 提交 -> CI 根据 Dockerfile 构建镜像 -> 推到镜像仓库 -> 服务器拉镜像运行
